# Backgrounds

**Category**: Background layers, canvas effects, texture fills, atmospheric decorators.
Use these as layers that sit *behind* content — never as primary content themselves.

> **Reuse first.** Before installing or copy-pasting, check if the component already exists in the project (`components/ui/` for Magic UI, anywhere in `components/` for Aceternity). If found, import and reuse it. Only fetch docs when the component is absent or you're unsure about props/dependencies.

## Guardrails

- Use at most 1 background component per viewport section.
- Ensure animated backgrounds do not reduce text contrast below WCAG AA.
- Prefer `pointer-events: none` on background layers to avoid blocking content interaction.
- For performance: avoid stacking multiple canvas/WebGL backgrounds in one viewport.
