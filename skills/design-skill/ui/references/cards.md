# Cards

**Category**: Card components, card-like containers, interactive panels, bento grids.
Use these to display content blocks with visual hierarchy and interactivity.

> **Reuse first.** Before installing or copy-pasting, check if the component already exists in the project (`components/ui/` for Magic UI, anywhere in `components/` for Aceternity). If found, import and reuse it. Only fetch docs when the component is absent or you're unsure about props/dependencies.

## Guardrails

- Avoid running hover animations on more than 3-4 cards simultaneously on one page.
- 3D tilt cards (3D Card Effect, Comet Card, Glare Card) should not be nested inside other animated containers.
- Card Spotlight and Evervault Card are dark-mode optimized — test contrast on light themes.
- For bento layouts: maintain consistent card heights where possible; use `grid-flow-dense` to fill gaps.
