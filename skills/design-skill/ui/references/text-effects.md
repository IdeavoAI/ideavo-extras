# Text Effects

**Category**: Text animation, typography effects, word/letter motion.
Use these to add emphasis and motion to headings, subheadings, and product messaging.

> **Reuse first.** Before installing or copy-pasting, check if the component already exists in the project (`components/ui/` for Magic UI, anywhere in `components/` for Aceternity). If found, import and reuse it. Only fetch docs when the component is absent or you're unsure about props/dependencies.

## Magic UI

### blur-fade
- **Library**: Magic UI
- **Vibe**: clean, subtle, elegant, entrance
- **Use-case**: Text (or any element) fades in with a blur-to-clear entrance animation — great for hero headings
- **Install**:
  ```bash
  npx shadcn@latest add @magicui/blur-fade
  ```

## Guardrails

- Use at most 1-2 text animation components per section — stacking multiple creates cognitive overload.
- Word cycling components (word-rotate, Flip Words, Container Text Flip) work best in hero headings only.
- Encrypted Text / Text Flipping Board are strong personality statements — use sparingly.
- Animated text must not cause layout shift (CLS) — test with `will-change` and fixed dimensions.
- Ensure animation respects `prefers-reduced-motion` media query.
